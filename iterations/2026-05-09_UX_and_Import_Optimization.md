# LocalKey 迭代记录 - 2026-05-09 (UX 与 数据管理优化)

## 1. 核心逻辑改进：精准路径匹配
*   **问题描述**：原逻辑在遇到带参数的 URL（如 `?union=xxx`）时会匹配失败，且侧边栏与网页端的匹配行为不一致。
*   **解决方案**：
    *   **网页端 (Content Script)**：引入“归一化路径匹配”。系统会自动剥离 URL 中的查询参数和 Hash，仅对比 Host 和 Path。支持“精确路径”和“子路径”匹配。
    *   **侧边栏 (Side Panel)**：应用户要求恢复了基于 Host 的宽口径匹配，确保用户在同一个域名的不同页面都能方便地看到该域名下的所有账号。

## 2. 交互体验增强：Alt + 1-9 快捷填充
*   **新增功能**：在当前网站有匹配账号时，支持通过键盘快捷键 `Alt + 1` 到 `Alt + 9` 快速触发填充。
*   **UI 提示**：
    *   **侧边栏**：在“快速填充”按钮上动态显示 `Alt+N` 蓝色角标。
    *   **网页端**：漂浮窗图标由首字母改为对应数字编号，Tooltip 增加快捷键说明。
*   **实时同步**：优化了 `content.js` 的渲染哈希逻辑，确保侧边栏配置修改后，网页端 UI 在 1 秒内自动完成重绘。

## 3. 设置中心：快捷键开关
*   **功能描述**：在设置页面新增“启用数字快捷键填充”开关。
*   **联动效果**：关闭开关后，侧边栏角标消失，网页端恢复为字母显示且屏蔽键盘监听，将选择权完全交给用户。

## 4. 数据安全：导入逻辑升级
*   **智能去重**：导入时以“网址 + 账号”为唯一标识进行校验。如果库中已存在相同账号，系统将自动跳过，防止数据冗余。
*   **URL 归一化**：去重校验时会自动处理 `http/https`、`www.` 以及末尾斜杠的差异，提高识别精度。
*   **结果报表**：导入结束后弹出详细统计弹窗，清晰告知用户：**成功新增数**、**自动跳过数**以及**格式错误失败数**。
*   **容错性**：采用 `try-catch` 循环，确保单条记录格式错误不会导致整个导入流程中断。
